# JLPT 演習課題

N5からN1までの静的な演習サイトです。文法、聴解、言語知識を、各級5回分ずつ解けます。

各回は5問、100点満点です。制限時間内に解答し、60点以上で合格、60点未満で不合格になります。聴解はブラウザの日本語音声で再生します。

問題は演習用のオリジナルで、公式試験の過去問ではありません。

## 開発

```bash
npm install
npm run dev
```

## 静的ビルド

```bash
npm run build
npm run preview
```

成果物は `dist/` です。ホスティング先が未知のパスを `index.html` に戻す場合に備え、同じ内容の `404.html` も出力します。
